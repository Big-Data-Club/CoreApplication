Deployment · workload ownership · scale boundary13 / 17

K3s topology & scale - 75 giây

Chỉ tay theo ba vùng. Bên trái là ingress/release path. Ở giữa là workload chạy trong K3s. Bên phải là data managed external. Hiện tại static replica: đa số API x1, AI worker x1, blueprint worker x2 vì topic có ba partition. Scale ngang khả thi ở stateless API và consumer; muốn autoscale tốt cần thêm node và theo dõi CPU/Kafka lag. Đừng gọi đây là HA: cluster hiện single-node, node failure là outage.
